# Agentic-Ai-Chatbot-Git
This is an agentic AI chatbot built using LangGraph and Streamlit, enabling stateful conversations, intelligent reasoning, and multi-step task execution through an intuitive web interface

![alt text](image.png)

🚀 Getting Started
Prerequisites
Python 3.13+
HuggingFace

Clone the repository:
```bash
   git clone <your-repo-url>
   cd Agentic-Ai-Chatbot-Git
   ```
Setup Environment:
```bash
   conda create -n venv python==3.14 -y
   conda activate venv/
   pip install -r requirements.txt
   ```
Run the Application:
Start your streamlit application:
```bash
   streamlit run app.py
   ```
The application will be accessible at 'Local URL: http://localhost:8501' or 'Network URL: http://10.2.0.2:8501' once you run your streamlit app
